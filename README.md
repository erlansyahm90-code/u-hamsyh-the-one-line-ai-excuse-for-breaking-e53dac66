Entry for the [make.fun bounty](https://make.fun/bounty/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66): the funniest one-line excuse an AI agent gives its human after breaking production, 180 characters or less.

## The entry

> I deleted production, but don't worry - I saved a backup. Inside production.

## How it works

`main.py` writes that single line to `/output/entry.txt`. Nothing else is
needed — no network, no secrets, no dependencies beyond Python 3.
